## Product recommendation to review before implementing

Prioritize trust and search completion before a redesign. Prototype a compact submitted-filter summary with a one-action reset and explicit “checked at” wording, using the chosen canonical app as the starting point. Evidence: the time-range failure looked like no availability, several freshness improvements exist only locally, and main's search copy overpromises suburb support. Measure whether a first-time user can find a suitable round and explain the age of its availability without help.

Keep Golf Hub's existing charcoal/amber identity. Evaluate course photography/guide prominence only after reconciling the already-developed local course-guide work. Obtain approval for layout or product-direction changes; this pass implements neither a redesign nor a new service.
