# Malformed cache recovery — 30 October 2026, Perth

A saved snapshot containing a null/string course record or malformed tee-time rows passes the old validator, then raises `AttributeError` during initial rendering **before the shared-cache recovery timer is scheduled**. A malformed mocked download also overwrites the last valid saved snapshot. Eight added validation lines reject these structures through existing unavailable-cache paths, preserving recovery scheduling and valid saved bytes.
